# Changelog

## 1.2.0

- Function and method names are light blue, declared or called, builtins included.
- Types and packages are neutral.

## 1.1.0

- Popups (suggest, hover, find/replace, quick pick) sit on a raised surface, and
  the selected row gets an accent tint.
- Blue is reserved for keywords (bold) and language literals like `nil` and `true`
  (not bold).
- Types, packages and builtin functions are light blue.
- Punctuation is bold purple: operators, brackets, and `,` `;` `.` `:`. Parts of a
  number literal stay with the number.
- Escape sequences and printf placeholders are gold instead of the default
  foreground.
- Markdown bold and italic are light blue, and link labels are neutral.
- Removed lines in a diff are brick red.

## 1.0.2

- Shorter description and README intro.

## 1.0.1

- Add extension icon.
- Marketplace metadata: keywords, gallery banner, homepage, and issues link.
- Rewrite the README as a proper listing.

## 1.0.0

- Initial release of **Leo Dark** — a low-contrast dark theme with muted blue
  accents, warm strings, and language-tuned syntax colors.
